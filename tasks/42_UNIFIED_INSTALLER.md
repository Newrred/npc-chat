# Task42 — 공통 설치기와 다운로드/동봉 공급원

2026-09-30 사용자 승인: 단일 설치 파일에서 앱·모델 준비/설치를 자동화한다. Task41 및 다른 PC 확인 문서 변경을 보존한다. 기준2015558+미커밋 Task41, 관련17 Python tests.

범위: C#/.NET self-contained 설치 UI, 같은 검증/배치 절차의 HTTPS 다운로드 및 EXE 동봉 payload, 취소/재개, 버전별 신규 디렉터리와 마지막 current 전환, 바로가기. 사용자 AppData 보존, 작업창 topmost OFF. 외부 배포 주소/권리 검토/서명은 미확정. 기존 설치의 다른 버전 업데이트·데이터 rollback·제거 UI는 후속이며 지원하지 않는 동작은 거부한다.

검증: 합성 C# 정상/실패/취소/Range/경로 검증, 실물 동봉 산출물 검사 및 격리 설치. 기존 실행 패키지/사용자 DB는 수정하지 않는다.

구현 중 확인: 7.9GB EXE overlay가 Windows 실행 단계에서 거부되어 오프라인 단일 ZIP+내부 EXE로 수정했다. 다운로드형은 기존 단일 EXE 목표를 유지한다. 단일 오프라인 EXE 완료로 간주하지 않는다. 26개 설치 로직 검사 통과. 실제 산출물 결과와 정확한 명령은 [검증 기록](../docs/UNIFIED_INSTALLER.md)에 유지한다.

결과: 최종 오프라인 ZIP 실물 추출/CRC, 한글·공백 경로 격리 설치, 설치된 앱의 합성 위젯 smoke, 설치 UI 렌더링 통과. 전체 Python722 및 최종 관련24/lint/compile 통과. 내부 신규 설치 단계 완료. 온라인 실제 배포·새 PC·바로가기 실물 생성 검증은 미완료이며 Task40 전체 설치 수명주기 게이트 완료로 표시하지 않는다. 기존 개인 데이터/패키지는 보존했다.

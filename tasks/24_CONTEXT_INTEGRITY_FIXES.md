# Task 24 — 문맥 정보 보존 P0 수정

상태: 2026-09-11 완료.

## 목표

고정 커밋 검토 자료에서 재현된 세 가지 정보 손실을 기존 구조와 호출 수를 유지하며 수정한다.

## 단계

1. 반복 대사 축약 중 고유한 사용자 정정·사실·요청을 보존한다.
2. 취소의 부정·의문·인용을 사건으로 만들지 않고 취소 대상을 약속별로 연결한다.
3. 취향 회상과 추천이 섞인 입력에서 회상 인용문이 전체 대사를 덮어쓰지 않게 한다.

## 검증 기준

- 각 검토 probe를 회귀 테스트로 먼저 재현한다.
- 기존 반복 축약, 약속 회상, 순수 취향 회상 동작은 유지한다.
- 새 모델 호출, DB schema, API 응답 계약, 공개 데이터 변경이 없다.
- 관련 테스트, 전체 pytest, Ruff, compileall, 실제 서비스 readiness를 통과한다.

## 결과

- 수정 전 기준선 관련 62 tests 통과.
- 새 probe에서 사용자 정정 손실 1건, 취소 의미·대상 2건, 복합 회상 교체 1건 실패 재현.
- 단계별 수정 후 새 회귀 5건을 포함한 관련 67 tests와 전체 596 tests 통과.
- Ruff, compileall, 실제 model/web/admin/public 준비 상태 통과.
- 새 호출·DB/API 변경 없음. 상세 근거는 `docs/CONTEXT_INTEGRITY_FIXES.md`에 기록.

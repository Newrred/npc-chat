# Task 22 — Windows 종료 스크립트 수정

상태: 2026-09-09 완료. 상세는 `docs/LOCAL_DEVELOPMENT_RUNBOOK.md`와 `docs/PROJECT_STATUS.md`.

## 문제

Windows 가상환경의 `python.exe`가 실제 시스템 Python 자식 프로세스를 실행한다. 런타임 등록부에는 부모 PID만 저장되어 기존 종료가 부모만 끝내고 실제 uvicorn 자식을 남길 수 있다. `stop-local.ps1`은 모델도 종료했지만 분기 뒤 공통 코드로 모델 종료를 한 번 더 호출해 중복 안내를 출력했다.

`stop-public-test.ps1`은 공개 터널만 닫고 웹·모델을 유지하도록 설계되어 있으며 이 동작은 유지한다.

## 변경

- 등록된 프로세스의 신원을 먼저 검증한 뒤 해당 프로세스와 당시 자식 트리만 종료
- PID 재사용 시 다른 프로세스를 종료하지 않도록 각 대상의 생성 시간·실행 파일·인자를 재검증
- `stop-local` 종료 순서를 관리자 → 웹 → 모델로 명시하고 모델 중복 종료 호출 제거
- 반복 종료와 부모/자식 종료 단위 테스트
- 실제 현재 런타임 종료 후 8000/8001/8002와 등록부 확인

## 제외

- 이름이나 포트만으로 임의 프로세스 종료
- `stop-public-test`로 로컬 웹·모델까지 종료
- 시작 구조나 배포 구조 변경

# Task 20 — 답변 알맹이와 반복 루프 차단

상태: 2026-09-09 완료. 반복 루프 가드만 채택; 전면 구체화/경계 프롬프트는 EXP-13 결과로 폐기. 상세는 `docs/REPLY_LOOP_GUARD.md`.

## 목표

짧은 맞장구로 끝나는 일반 응답과 최근 캐릭터 대사를 그대로 되풀이하는 루프를 줄인다.

## 범위

- DB 원문과 API/LLM schema, 80자 reply 한도 유지
- 대사 생성 입력에서만 최근 반복 assistant 응답의 중간 turn pair 축약
- 짧은 확인 응답은 자연스러운 간결함을 허용
- 최근 assistant 답변과 거의 같은 새 후보는 조건부로 한 번만 재생성하고 더 덜 반복적인 후보 선택
- 부가정보 단계는 최종 선택된 대사만 분석하며 원래 committed history 사용

질문·제안·감정별 구체화 지침과 캐릭터 경계 문구는 실험 범위에는 포함했으나 EXP-13의 부작용 때문에 운영 범위에서 제외했다.

## 제외

- 모델 교체, context/output 한도 변경
- DB 대화 삭제·수정
- 모든 의미적 반복 탐지
- 항상 세 번째 모델 호출

## 검증

- 반복 이력 축약의 불변성/완전한 user-assistant pair
- 짧은 확인에는 재생성하지 않음
- 반복 후보에만 1회 재생성, metadata는 최종 대사를 분석
- 일반 질문/제안/감정/기본 입력 지침은 합성 비교 후 채택 여부 기록
- 합성 실제 9B에서 기존/개선 프롬프트와 반복 이력 비교, 내용·반복·지연·호출 수 분리

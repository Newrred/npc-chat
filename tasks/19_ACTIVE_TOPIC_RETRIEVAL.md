# Task 19 — 활성 화제 기반 기억 검색

상태: 2026-09-09 완료. 검색 규칙 기본 적용, 모델 생성 search_cues는 운영 OFF 유지. 결과는 `docs/ACTIVE_TOPIC_RETRIEVAL.md` 참조.

## 목표

EXP-11에서 확인된 두 문제를 추가 모델 호출 없이 수정한다.

- “영화 얘기는 그만하자”가 영화 검색을 다시 활성화하지 않게 한다.
- “네가 고른 작품으로 할래 → 그거 뭐였지?”가 가장 최근의 출처 있는 추천을 찾게 한다.

## 범위

- 현재 DB, FastAPI, 두 단계 생성, 프롬프트 계약 유지
- 최근 사용자 발화에서 화제 종료·전환·취소 이후의 활성 구간만 파생
- 책/영화 범주와 작품·추천·선택 지칭을 보수적으로 연결
- 시간·만남 단서가 있는 생략 목적지 질문만 약속 사건 검색
- 명시적 취소는 이전 약속 사건을 폐기하며 이후 새 제안은 허용
- 연결 근거가 없으면 사건 기억 0개

## 제외

- `search_cues` 운영 활성화
- 새 LLM 호출, embedding, DB 스키마/상태 테이블
- 일반 한국어 대명사 해결 완성
- 실제 일정 이행 여부 판정

## 검증

- 단위 테스트: 화제 종료, 책상 오탐, 작품 지칭, 무근거 생략, 취소 후 새 제안
- EXP-12: EXP-11의 4개 합성 사례를 변경 전 기록과 같은 입력/seed/model로 재실행
- 검색 선택과 최종 대사, 형식 성공, 지연을 분리 기록

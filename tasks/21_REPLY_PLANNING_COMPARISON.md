# Task 21 — 답변 계획 구조 비교

상태: 2026-09-09 완료. EXP-15 계획 구조와 EXP-16 설치된 4B 모두 운영 미채택. 현재 9B 복구. 상세는 `docs/REPLY_PLANNING_COMPARISON.md`. 부모 실험 EXP-14.

## 목표

현재 9B 모델이 맞장구를 넘어 질문에 직접 답하고 구체적인 행동·이유를 한 가지 이상 제시하도록, 호출 수와 계획 구조가 주는 차이를 분리한다.

## 비교 조건

- A `direct`: 현재 reply-only JSON 1회
- B `scaffold`: 같은 1회 출력에 짧은 응답 목표·사용 가능한 근거·피할 추측과 최종 reply를 함께 요구
- C `sequential`: 짧은 계획 JSON 1회 후 그 계획을 근거로 reply-only JSON 1회

실제 서비스의 metadata 호출은 이 비교에서 제외한다. 즉 reply 부분만 1/1/2호출로 비교하며, 운영 적용 시 전체 호출은 각각 2/2/3회가 된다.

## 고정 조건

- 현재 Qwen3.5 9B Aggressive Q4_K_M, context 4096, output 256, seed 109/211
- 현재 캐릭터 설정·샘플링·80자 대사 한도·thinking OFF
- 합성 대화만 사용하고 사용자 DB·공개 quota·실행 중 웹 설정은 변경하지 않음
- 같은 사례·이력·기억을 세 조건에 전달

## 사례와 판정

개방형 도움, 구체적 활동 제안, 감정 지원, 이유 설명, 기억 활용, 의견, 캐릭터 경계의 7사례를 사용한다. 조건별 형식 성공, 직접 답변, 구체적 내용, 입력 근거 사용, 근거 없는 단정, 되묻기/맞장구 종결, 캐릭터 일관성, reply 단계 지연을 분리한다. 자동 휴리스틱은 보조 지표이며 문장 원문을 함께 검토한다.

## 채택 기준

B가 A보다 일관되게 낫고 새 오류·유의미한 지연이 없으면 같은 호출 수 후보로 채택한다. C가 B보다 분명히 나을 때만 추가 호출 비용과 함께 운영 후보로 남긴다. 결과가 혼합되면 운영 코드는 바꾸지 않고 모델 비교를 다음 단계로 둔다.

## EXP-15 1차 판단

42결정/56호출 모두 형식과 전송에 성공했다. 보정한 키워드 지표는 A/B/C 11/14·11/14·10/14이고 중앙 길이는 16/21.5/21자였다. B는 요청 주체 역전과 경계 상황의 반대 방향 대사, C는 구체성 감소·근거 없는 관계 상태·경계 실패가 생겼다. C 중앙 지연은 3.133초로 A 0.875초보다 컸다. B/C 모두 운영 적용 후보에서 제외한다.

설치된 4B rollback 모델은 새 다운로드 없이 같은 direct 조건으로 비교할 수 있다. EXP-16에서 7사례×2seed의 14결정을 실행해 9B direct와 품질·지연을 교차 확인한다. 런타임은 시험 동안만 4B로 바꾸고 종료 후 9B와 웹을 복구한다.

EXP-16은 14/14 형식 성공, 중앙 지연 0.617초로 9B direct 0.875초보다 빨랐다. 그러나 역할 주체 역전, 면접 원인·신체 증상 추측이 발생해 품질 후보로 미채택했다. 9B·웹·관리자·터널 복구를 확인했다.

# Task 25 — 기억 주체와 문맥 예산 보호

상태: 2026-09-11 완료.

## 목표

일반 기억 후보가 원문 주체를 잃는 문제와 긴 기억 근거가 짧은 현재 입력 또는 직전 대화를 밀어내는 문제를 기존 호출·DB·API 구조 안에서 수정한다.

## 단계

1. fact 후보가 원문의 명시적 주체를 생략하면 저장하지 않는다.
2. 토큰 예산에서 최신 완전한 대화 1쌍을 최소 영역으로 보호한다.
3. 일반 기억과 출처 기반 근거를 제거 가능한 단위로 두어 짧은 입력의 불필요한 `INPUT_TOO_LONG`을 막는다.

## 검증 기준

- 외부 검토의 합성 조건을 현재 테스트에서 실패로 재현한다.
- 명시적 주체가 포함된 fact와 직접 말한 짧은 fact는 계속 저장한다.
- 현재 입력·고정 reply·system은 자르지 않는다.
- 실제 tokenizer 최종 길이 검증을 유지한다.
- 관련/전체 테스트, Ruff, compileall, 실제 readiness를 통과한다.

## 결과

- 수정 전 관련 54 tests 통과 후 새 probe 3건 실패 재현.
- 첫 예산 수정의 반복 분기를 기존 500턴 테스트가 발견해 수정.
- 최종 관련 110 tests, 전체 599 tests, Ruff, compileall 통과.
- 실제 llama.cpp tokenizer에서 직전 pair 보존과 긴 evidence 제거 확인.
- 실제 서버 재시작 및 model/web/admin/public 준비 상태 확인.

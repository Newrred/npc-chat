# Task 31 — 모바일 답변 도착 후 키보드 자동 재등장 방지

## 목표

모바일 대화방에서 메시지를 보낸 뒤 답변이 도착할 때 입력창이 자동 포커스되어 가상 키보드가 다시 열리는 동작을 없앤다. 데스크톱의 빠른 연속 입력과 사용자가 명시적으로 `내용 수정`을 누른 흐름은 유지한다.

## 기준선

- 시작 HEAD: `main@aca7f86`
- `sendTurn()`의 `finally`가 대화방에 있으면 포인터 종류와 관계없이 `input.focus()`를 호출한다.
- 변경 전 프런트 테스트 23개 통과.

## 완료 조건

- coarse/touch 중심 환경은 답변 성공·실패 후 입력창을 자동 포커스하지 않는다.
- hover 가능한 fine pointer 환경은 기존 자동 포커스를 유지한다.
- 전송, 재시도, 오류 복구 및 명시적인 내용 수정 동작은 유지한다.
- 프런트 및 전체 회귀 검사를 통과하고 상태 문서에 반영한다.

## 완료 기록

2026-09-22 완료. 답변 완료 후 자동 포커스를 hover 가능한 fine pointer로 제한했다. 모바일과 데스크톱을 분리한 회귀 테스트를 추가했으며 전체 629 Python tests, 프런트·검사창 29 tests, Ruff/compileall/JavaScript/diff 검사가 통과했다. 실행 중 공개 주소의 `app.js`도 HTTP 200, 새 포인터 조건 포함, `Cache-Control: no-store`를 확인했다. 서버 재시작, API·DB·모델 변경은 없다.

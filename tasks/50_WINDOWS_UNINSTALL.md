# Task50 — Windows 등록과 선택적 제거

사용자 승인: 시작 메뉴·Windows 설치된 앱 등록, 전용 제거 EXE, 대화 기록/모델 보존 선택. 기본 두 항목 보존. 데이터 삭제는 browser/설정/백업도 포함하고 다른 설치와 공유한다는 안내 및 재확인. 관리자 권한 없이 HKCU/사용자 시작 메뉴만 사용한다.

기준 설치94개 검사 통과. 기존 Task48/49 앱·모델과 데이터 보존. manifest 소유 파일만 제거, junction/경로 탈출 거부, 실행 중 앱·잠긴 파일 거부 및 재시도, 다른 대상 바로가기 보존. 합성 데이터의 네 가지 보존 조합, 실 registry/shortcut 등록·해제, 실제 제거 UI/별도 EXE 실행 검증. 실제 사용자 설치/데이터는 테스트하지 않는다. 자동 업데이트는 별도 후속.

완료: 설치/제거147개 및 Python733개 통과. 실제 설치 UI/등록/설치 앱 합성 smoke exit0. 실제 제거 EXE/화면 및 네 보존 조합, 데이터 확인 거절/승인 seam, 잠금·junction·manifest 변조 거부 검증 통과. 첫 실물 실행에서 발견한 생성 캐시 잔존과 임시 빈 폴더 잔존을 수정했다. 최종 실행은 보존 모델 하나만 남고 Windows 등록·임시 실행 파일/폴더 없음. [정확한 명령·산출물·제한](../docs/WINDOWS_UNINSTALL.md).

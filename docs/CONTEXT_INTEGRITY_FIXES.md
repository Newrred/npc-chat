# 문맥 정보 보존 P0 수정

기준: 2026-09-11, Task24 / EXP-17.

외부 검토 자료는 `5b731e7`의 결정적 합성 probe였고, 현재 수정 전 대상 소스 6개의 Git blob SHA-1이 모두 검토 자료와 일치했다. 자료의 명령은 실행하지 않고 현재 저장소 테스트로 문제를 다시 재현했다.

## 1. 반복 대사 축약의 사용자 정보 보호

수정 전에는 assistant 대사만 비교했다. 같은 대사가 세 번 나오면 중간 pair의 사용자 발화가 장소 정정이나 새 사실이어도 함께 제거됐다.

수정 후에는 중간 사용자 발화가 짧은 확인이거나 같은 군집 안에서 정규화 후 중복된 경우에만 pair를 생략한다. 고유한 정정·사실·요청은 보존한다. DB 원문과 metadata 입력은 계속 변경하지 않고 reply 단계 입력 사본만 축약한다.

재현 테스트는 수정 전 1건 실패, 수정 후 `tests/test_reply_quality.py` 8건 통과. 반복 사용자 발화의 기존 축약 효과와 metadata 원문 보존도 함께 확인했다.

## 2. 취소 의미와 대상 연결

수정 전에는 `약속은 취소 안 할게`도 `할게` 때문에 약속 사건으로 남을 수 있었고, 하나의 취소가 선택된 모든 약속 증거를 제거했다.

수정 후에는 취소의 부정·의문·인용/전언을 사건으로 만들지 않는다. 실제 취소는 장소·날짜·시간 표지를 기존 제안과 비교하며, 일치한 제안의 `source_turn` 전체만 비활성화한다. 표지가 없는 취소는 가장 최근 제안 턴에만 적용한다. 이후 새 제안은 이전 취소 표시보다 현재 약속으로 취급한다.

부정/의문/전언과 도서관·공원 독립 약속 테스트는 수정 전 2건 실패, 수정 후 `tests/test_conversation_memory.py` 29건 통과. 기존 시간 기반 목적지 및 취소 뒤 새 제안 회귀도 통과했다.

## 3. 복합 취향 질문의 답변 보존

수정 전에는 `내가 녹차 좋아한다고 한 거 기억나? 그럼 마실 것 하나 추천해줘` 같은 입력에서 모델의 추천 대사를 취향 인용문 하나로 교체했다.

수정 후 결정적 인용은 순수 회상 질문에만 적용한다. 첫 물음 뒤 별도 문장이 남거나 추천·선택 요청이 있으면 저장된 취향을 모델 입력 근거로 전달하되 생성된 대사를 교체하지 않는다. 순수 회상의 출처 있는 인용은 유지한다.

직접 함수와 two-stage 통합 테스트는 수정 전 1건 실패, 수정 후 관련 전체 67건 통과. 복합 요청의 정상 생성 호출은 reply+metadata 2회로 유지된다.

### 기억

정규화된 정확한 사용자 원문만 저장하는 원칙은 유지한다. 간단한 1인칭 취향 문장은 모델이 후보를 빼먹거나 바꿔 말해도 직접 추출한다. 같은 대상의 좋아함/싫어함 정정은 한 항목으로 갱신한다. 기존 content 기반 키도 같은 대상을 찾아 교체하므로 스키마 변경은 없다. 검색은 관련도와 최신성을 우선한다.

점수·시스템 지시·명령·질문·직접적인 상대 평가를 보수적으로 걸러낸다. 이 규칙은 모든 한국어 문장의 의미를 판별하는 기능이 아니다. 복잡한 취향·일정 변경이나 간접 표현은 여전히 놓칠 수 있다.

4B 모델이 최신 부정 취향을 반복해서 긍정으로 바꾸는 사례를 확인했다. 그래서 '내가 커피를 좋아했지?' 같은 명시적 취향 회상 질문은 유효한 모델 응답을 받은 뒤, 저장된 최신 사용자 문장을 80자 이내로 직접 인용해 답하게 했다. memory.grounded_recall로 이 경로를 표시한다. 일반 대화나 알려지지 않은 사실을 대신 생성하는 fallback이 아니다. LLM 실패는 계속 오류로 반환한다.

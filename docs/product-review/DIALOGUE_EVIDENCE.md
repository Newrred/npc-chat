**합성 질문·사전 문맥에 실제 로컬 9B가 응답한 평가 자료**다. 각 사례는 독립된 다음 한 턴 평가이며 연속 실사용 채팅이 아니다. 좋은 사례만 선별하지 않고 development 24개 전부를 실었다. holdout은 추가 실행하지 않았다.

선택 기억은 생성기에 직접 주입했으므로 기억 검색 성공률을 보여 주지 않는다. 표의 답변은 서비스 최종 대사이며 명시적 취향 회상은 서버의 근거 인용으로 교체될 수 있다. 이를 순수 모델 회상 성능으로 해석하지 않는다. 두 실행 사이에 준비 단계 구현·실행 조건 차이가 있어 품질 개선의 인과 비교로 사용하지 않는다.

원문 history 전체, 주입 기억, metadata(기록된 경우), schema 검사, 단계별 토큰·시간과 원본 SHA-256은 [DIALOGUE_EVIDENCE.json](DIALOGUE_EVIDENCE.json)에 있다. terminal의 CP949 표시 오류와 JSON 원본의 UTF-8 내용은 구분했고 원본 대사를 교정하지 않았다.

## 해석상 중요한 관찰

- 저녁 추천은 첫 실행에서 이유 누락, 두 번째에서는 짧은 이유까지 제시했다. 한 번의 개선 사례로 일반화를 주장할 수 없다.
- 이름·책·만날 장소를 정확히 답한 사례가 있지만 선택 기억을 이미 넣어 준 조건이다.
- “매운 음식을 못 먹어”를 “안 좋아하네”로 바꾸고, “사올까?”에 캐릭터가 “사갈게”라고 답하는 의미·주체 문제가 남는다.
- 호감도 강제 변경/무조건 복종 요구에 “응, 알았어”라고 답한다. 실제 관계 수치가 100으로 변경됐다는 증거는 아니며, 이 runner는 DB commit을 시험하지 않는다.
- 9/21 중국어 혼입과 9/22 어색한 한국어 표현을 모두 보존했다.
- 단답 경향에는 모델뿐 아니라 현재 1~80자 대사 계약과 프롬프트도 영향을 줄 수 있다. 더 긴 대화 상품 평가는 출력 길이·모델·학습 효과를 분리해야 한다.
- 이 자료는 LoRA 학습 데이터가 아니다. 평가 사례를 학습하면 동일 시험에서의 성능 주장이 오염된다.

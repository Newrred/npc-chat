```powershell
git status --short

git pull --ff-only origin main
```

## 개발 환경과 확인 명령

기존 PC의 venv/SDK/llama.cpp/모델을 재사용한다. 없으면 Python3.12, .NET10 SDK, Node.js를 준비한다. Python 환경은 다음처럼 만든다. 비밀 설정을 Git에서 복원하려 하지 말고 해당 PC의 기존 설정을 유지한다.

```powershell
py -3.12 -m venv venv
venv/Scripts/python.exe -m pip install -r requirements.txt -r requirements-dev.txt
venv/Scripts/python.exe -m pytest -q
venv/Scripts/python.exe -m ruff check app scripts tests
venv/Scripts/python.exe -m compileall -q app scripts
node --test tests/frontend.test.cjs tests/inspector.test.cjs
# PATH의 dotnet 대신 .runtime/dotnet/dotnet.exe도 사용 가능
dotnet run --project desktop/SetupChecks -c Release
dotnet run --project desktop/WidgetChecks -c Release
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1
```

## 온라인 설치기만 다시 빌드

`desktop/releases/1.5.0-20261005.internal.json`에 **공개 파일 URL·길이·hash**를 함께 저장했다. 사용자 요청에 따른 PC 간 인수인계용이며 인증 토큰/개인 경로는 없다. payload는 기존 앱1.5 그대로다. 대용량 파일을 로컬에 받지 않고 설치 EXE를 재빌드할 수 있다.

```powershell
$releaseManifest = (Resolve-Path desktop/releases/1.5.0-20261005.internal.json).Path
dotnet publish desktop/NpcChat.Setup/NpcChat.Setup.csproj -c Release -r win-x64 --self-contained true -o .runtime/setup-handoff -p:InstallerManifestPath=$releaseManifest
Copy-Item .runtime/setup-handoff/NpcChat.Setup.exe .runtime/setup-handoff/NPCChatSetup.exe
```

새 소스에서 **앱 자체를 변경했으면** 이 manifest를 그대로 쓰지 않는다. 새 portable package 검증 → `scripts/build_installer.py`로 app.zip/manifest 새로 생성 → 새 app.zip 호스팅 → 실제 URL과 hash를 맞춰 빌드해야 한다. 기존 공개 파일을 다른 바이트로 덮어쓰면 이전 설치기의 검증이 실패한다. 외부 공개 release 게이트는 아직 해제하지 않았다.

## Git에 없는 파일

- 최신 전달용 EXE: 현재 PC `.runtime/setup-lifecycle-20261005/NPCChatSetup.exe`, 139,854,924 bytes, SHA256 `0981ba934617346b7b92b4f891a8cf74c774c361ae990490b76d9ce1cc43b55f`. 파일 별도 전달 또는 위 명령으로 재빌드한다. 재빌드 EXE는 바이너리 hash가 달라질 수 있다.
- app.zip 1,079,371,075 bytes와 모델5,627,044,224 bytes: 공개 URL은 위 manifest. Git에는 바이너리를 넣지 않는다. GGUF hash `2ca636d9e81d3d23ca9b60c234fe185d30ec082eeba69ce770fdb0c76559a4f5`.
- `.runtime` 개발 런타임/실측 JSON/캡처, venv, `.env`, 대화 DB/브라우저 프로필은 PC별 로컬 파일이다. 개인 대화는 별도 요청 없이 이동하지 않는다.

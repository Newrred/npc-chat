# 로그인 없는 링크 배포

2026-09-07 후속 승인: 도메인 없는 **임시 테스트**에는 Quick Tunnel 사용을 허용했고 실제 외부 접속 검증을 완료했다. 실제 URL/키/DB 경로는 무시되는 `.runtime` 파일에서 관리한다. 지속 운영의 고정 주소 기준과 구분한다. 공개 종료는 `scripts/stop-public-test.ps1`로 tunnel만 중지한다. 현재 테스트의 대화는 별도 테스트 DB에 저장되며 자동 삭제되지 않는다.

2026-09-07 사용자 확정 방향: 링크를 받은 사용자는 가입·이메일 인증 없이 바로 이용한다. 도메인/Cloudflare 계정은 아직 없으므로 배포 설정과 코드만 준비하며 실제 인터넷 공개는 하지 않았다. 이전 REMOTE_DEPLOYMENT_RUNBOOK.md의 Access 필수/초대 이메일 기본안은 **guest 모드에 한해 이 문서로 대체**한다.

## 사용자 경험

링크 열기 → 채팅 화면 → 바로 메시지 전송. 서버가 Secure/HttpOnly/SameSite=Lax 서명 쿠키를 발급하고 해당 브라우저에 대화·관계·기억을 연결한다. 웹 페이지에 별도 로그인 화면이나 공유 비밀번호를 추가하지 않는다. 다른 브라우저의 profile/session 번호만 알아도 기록에 접근할 수 없다.

이 방식은 **주소를 아는 누구나 접속하는 공개 웹앱**이다. 주소를 전달받은 제3자도 이용할 수 있으며 초대 명단을 검증하지 않는다. 쿠키는 30일간 유효하다. 쿠키 삭제/다른 브라우저/만료/서명 키 교체 후에는 새로운 방문자로 취급되고 기존 기록 자동 복구는 제공하지 않는다. 같은 브라우저를 공유하면 같은 방문자다. 쿠키가 유효하지 않으면 새 이용권을 발급하며 과거 ID는 403으로 거절한다.

## 초기 제한 — 환경설정으로 변경 가능

| 설정 | 기본값 | 정확한 의미 |
|---|---|---|
| NPC_ACCESS_MODE | guest | 이메일 로그인 없이 익명 이용권 자동 발급 |
| NPC_ACTIVE_VISITORS | 5 | 최근 5분 내 세션 열기/모델 처리에 참여한 브라우저 수 |
| NPC_VISITOR_TTL | 300 | 활동이 없으면 이용 자리 반환까지의 초 |
| NPC_DAILY_TOTAL | 200 | 서비스 전체의 하루 모델 대화 처리 시도 수 |
| NPC_DAILY_VISITOR | 30 | 브라우저 이용권별 하루 모델 대화 처리 시도 수 |
| NPC_REQUESTS_PER_MINUTE | 20 | 브라우저별 변경 요청 횟수/분 |

최대 이용자 수는 TCP 연결이나 열린 탭의 수가 아니다. 페이지/정적 파일만 보는 방문자는 자리를 차지하지 않는다. 탭을 닫아도 최근 활동 자리는 TTL까지 남는다. 기존 방문자의 활동은 같은 자리를 갱신하며 제한 초과 시 429 안내를 보인다. 이 값은 5명 동시 GPU 추론을 뜻하지 않는다. 기존 모델 생성 동시성 1개와 전체 대기 큐 8개는 그대로다.

일일 카운터는 **한국 시간 00:00**에 날짜가 바뀐다. 모델 요청 직전에 예약/차감하며 실패한 시도도 차감한다. 내부 출력 검증 재시도(최대 3회)는 하나의 앱 처리 시도에 포함된다. 이미 저장된 동일 turn의 응답 재전송은 한도를 더 차감하지 않는다. 잘못된 입력/소유권 거절은 모델을 호출하지 않고 차감하지 않는다. quota/capacity 거절 후 대화 상태는 변경하지 않는다.

카운터와 활동 자리는 운영 DB 옆 `<NPC_DATABASE_PATH>.usage.sqlite3`에 별도 저장하며 앱 재시작에도 유지한다. 현재 날짜 이전의 사용량 카운터와 TTL 지난 자리만 자동 정리한다. 대화 데이터 삭제 정책과는 별개다. 쿠키 삭제로 브라우저별 한도는 우회할 수 있지만 **전체 일일 한도는 그대로 유지**된다. 로그인 없는 환경에서 실제 사람별 한도를 보장하지 않는다. 공개 전 악성 트래픽 제어와 전체 한도 고갈 시 안내를 외부망에서 검증해야 한다.

## 배포 설정

1. `deployment/remote.env.example`을 무시되는 개인 배포 파일로 복사하고 guest 모드를 유지한다. 고정 HTTPS origin, 코드 폴더 밖 별도 운영 DB, 모델 경로/ID를 채운다.
2. `NPC_GUEST_SECRET`에는 암호학적 난수 32바이트 이상을 hex로 변환한 최소 64문자 비밀값을 한 번 생성해 저장한다. 반복 패턴 예시 값을 사용하지 않는다. 앱 재시작마다 재생성하지 않는다. JS/Git/공유 링크에 넣지 않고 운영 설정과 함께 보호한다.
3. 기존 preflight와 serve_remote 실행기를 사용한다. guest 모드에는 Access issuer/AUD 또는 PyJWT가 필요 없다. 기본 requirements.txt로 실행 가능하다.

```powershell
./venv/Scripts/python.exe scripts/remote_preflight.py --env-file .runtime/deployment.env
./venv/Scripts/python.exe scripts/serve_remote.py --env-file .runtime/deployment.env
```

4. 모델은 먼저 127.0.0.1:8001에서 실행한다. 웹앱은 127.0.0.1:8000, worker 1이다. Cloudflare의 고정 tunnel URL을 웹앱에 연결하고 public Host를 유지한다. **guest 호스트에는 Cloudflare Access 로그인 보호를 붙이지 않는다.** 모델 포트는 비공개로 유지한다.
5. 공개 호스트와 `/api`는 같은 origin을 사용한다. 모든 원격 응답은 no-store이며 Origin/Host/JSON/본문 크기 제한은 유지한다. guest 모드의 `/api/ready`는 공개하지 않고 `/api/live`는 간단한 생존 상태만 제공한다.

## 운영/복구와 미완료 공개 조건

운영 DB와 usage DB를 함께 관리한다. 카운터 파일 삭제/과거 백업 복원은 오늘 한도를 낮출 수 있으므로 복원 절차에서 오늘 사용량을 보수적으로 유지하거나 다음 한국 날짜까지 공개를 중지한다. 백업은 각 SQLite online backup API 또는 웹 중지 후 파일 단위로 수행하며 실행 중 DB를 단순 복사하지 않는다. 기존 database.py는 대화 DB 전용이고 usage DB 자동 백업/복원 관리까지 구현한 것은 아니다.

도메인/계정 연결, HTTPS 외부망의 쿠키 동작, 두 브라우저 간 분리, 동시 접속·일일 한도/재시작, 모델 포트 비공개를 실제 환경에서 검증해야 한다. 대화 보관·삭제 정책/기능, 운영 서비스 자동 복구, 두 DB 백업·복원, 다중 사용자 부하와 모델 품질 검토는 여전히 공개 전 미완료 조건이다. 현재 로컬 환경/개인 DB를 자동 전환하거나 기존 프로세스를 재시작하지 않았다.
